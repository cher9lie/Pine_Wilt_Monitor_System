10 平台交互
10.1 科研院所门户
10.1.1 监测数据申请
功能描述：为科研人员提供规范化、可追溯的数据获取通道。支持科研人员在线提交数据使用申请，需填写研究目的、所需数据类型（遥感影像/监测点位/评估报告）、时空范围、使用期限、成果形式（论文/专利/报告），上传单位盖章的保密承诺书。科研人员进入数据申请界面，系统展示可申请的数据目录（按数据类型/时间/区域组织），支持在线预览样本数据（低分辨率缩略图/脱敏样本）。申请人填写申请表单，系统自动生成申请编号与预计审批时间。审批过程中，申请人可实时查看审批进度（待预审/预审通过/人工复核中/已批准/已驳回）。批准后，系统自动生成数据使用协议（电子签章），数据打包（含数据文件+元数据+使用说明）并通过加密链接发送，有效期限制。
原子功能：
可申领数据动态目录树检索：系统按数据类型、时序与行政区划构建动态资源树，支持科研人员高效检索可申领的资产范围。
样本数据在线合规脱敏预览：动态生成低分辨率图像缩略图或表格局部脱敏样本，供申请人员在审批前进行在线可用性评估。
申请单全生命周期进度追踪：系统自动分发申请单编号，实时同步并可视化展示从预审、复核到批准/驳回的各节点审批流状态。
受控数据加密打包与限时分发：审批通过后自动关联电子协议，将目标数据集、元数据及 README 包裹加密压缩，生成具备到期自动销毁机制的限时下载链接。
技术支撑：电子签章采用 CA 证书+PDF 数字签名，具备法律效力。数据打包与限时下载采用带有生命周期（TTL）控制的分布式对象存储安全预签名 URL（Presigned URL）技术。
10.1.2 学术共研申请
功能描述：是与科研院所门户的协同创新机制，推动平台与科研机构的深度合作。学术共研申请支持科研人员提交联合研究提案，包括研究背景、技术路线、预期成果、资源需求（数据/算力/经费），经专家委员会评审后立项。科研人员提交联合研究提案后，系统分配至操作员进行评审，评审维度包括：创新性、可行性、预期价值、资源匹配度。评审通过后，双方在线签署合作协议，明确数据使用范围、知识产权归属、成果发表规范、经费分担比例。
原子功能：
联合研究提案多维提报：提供结构化的项目申报书填写界面，支持背景、技术路线、预期成果及所需资源（算力/数据/经费）的分段式上传与提交。
专家委员会多维指标量化评审：为平台评审专家提供专属面板，支持从创新性、可行性、价值度、资源匹配度等维度进行百分制量化评分与意见签署。
知识产权与成果发表规范备案：在线留存共研合作协议，对双方约定的数据边界、产权归属、经费比例及论文署名规范进行线上数字化归档。
技术支撑：合作协议采用智能合约模板，关键条款自动填充与校验。系统底层采用结构化表单引擎动态渲染项目申报书，采用哈希校验码保证申报附件的防篡改。
10.2 政府部门门户
10.2.1 政策发布
功能描述：是政府部门门户的权威信息发布通道，确保政策传达的及时性、准确性与可追溯性。政策起草人提交政策上传审核，支持多级审核（部门负责人→分管领导→主要领导）。审核通过后选择发布范围：全市公开、指定县区、指定层级（仅领导可见）。政策到期后自动归档至政策库，支持全文检索与历史版本对比。
原子功能：
政策公文多级线上三审：提供标准行政公文流转界面，支持政策起草、部门负责人预审、分管领导复审、主要领导终审的逐级审批。
发布范围精准投递控制：支持按行政地理区划（指定县区）及行政职级层级组合配置发布策略，执行定向可见性控制。
到期政策自动归档与版本对比：实时监测政策时效，到期文件自动标记为历史档案，提供正文文本内容的行级 Diff 差异对比。
技术支撑：发布范围采用 RBAC 数据权限+动态 SQL 拼接，确保精准投递。全文检索采用 Elasticsearch 搜索引擎，支持公文词条的智能分词与高亮检索。
10.2.2 统计灾情数据
功能描述：是政府部门门户的数据决策支撑，为领导提供多维度、多视角的疫情数据分析。界面默认展示本辖区疫情总览（累计疫木数、新增疫木数、疫情面积、防治进度），支持时间维度切换与区域维度切换。点击任一指标可下钻至明细数据（如点击“累计疫木数”展开各乡镇排名、重点林场列表、单株坐标分布）。数据支持导出为 Excel、PDF、图片（导出时自动添加水印）。
原子功能：
辖区灾情时空多维透视大屏：提供本辖区累计/新增疫木、疫情面积及除治进度的多维统计看板，支持按时间轴与行政树一键切换。
核心业务指标无缝下钻分析：支持从宏观统计指标一键穿透下钻至乡镇排名、小班清单、直至最底层的单株疫木空间坐标分布。
多格式数字化报表防伪导出：支持将当前统计视窗内容无损转化为 Excel 账册、PDF 简报或高清图片，并在导出流中强制注入防伪数字水印。
技术支撑：地图可视化，支持海量点数据聚合与热力渲染。底层采用 OLAP 实时大数据分析引擎（如 ClickHouse）实现亿级时空要素在毫秒级的聚合计算。
10.2.3 决策调度记录
功能描述：实现突发疫情时的快速响应与资源统筹的实时记录。实时记录领导在应对疫情时的各种任务指令，任务完成后自动生成指挥日志，包含时间线、决策链、资源消耗、成效评估，支持战后复盘。
原子功能：
应急指挥任务指令实时录入：提供突发疫情下的事件流速记与指令分发界面，实时挂接责任主体、影响范围与执行期限。
战后复盘指挥日志全息生成：任务闭环后，系统全自动提取并编排指挥日志，将时序演进、决策路径与成效结果在线关联。
技术支撑：决策要点提取采用关键词提取，自动生成摘要；指挥日志采用时间轴可视化，支持缩放与事件筛选。
10.3 保险公司门户
10.3.1 结果报告下载
功能描述：为保险公司门户的核心数据服务，为保险业务提供权威的风险评估依据。在权限范围内（已投保区域）查询可下载报告列表，包括：区域风险评估报告（年度/季度）、灾情事件报告（单次灾害）、趋势分析报告（多年对比）。报告内容经脱敏处理、报告嵌入数字水印、下载记录自动审计、异常行为触发风控告警。
原子功能：
投保视窗权限内报告检索：依据保险公司的空间承保边界，动态过滤并输出该林区内相关的年/季评估、单次灾害及趋势报告清单。
报告文本内容分级脱敏处理：在文件输出流中自动执行正则与空间脱敏，抹除敏感林相所有者、军事设施周边等涉密要素。
异常下载行为风控实时审计：对报告调取行为执行后台全时段无感审计，实时评估下载频次与时空集中度，抓取潜在的盗爬风险。
技术支撑：下载风控采用滑动窗口算法，检测异常频率，触发后自动限制并通知管理员。报告文件采用空域/频域隐形盲水印（Digital Watermarking）技术，确保即使截图或打印仍可实现源头追溯。
10.3.2 合作协同
功能描述：与保险公司共建生态机制，推动监测数据与保险业务的深度融合。保险公司提交合作意向后，平台商务团队对接洽谈，明确合作模式、服务范围、费用标准、结算周期。达成一致后在线签署合作协议，上传合作信息合同等，开通专属服务通道。
原子功能：
生态合作意向一键提报：为意向保险机构提供线上联络面板，支持合作模式需求、期望服务林区及业务联系方式的提报。
商业合作合同数字化建档：提供合作协议、结算账期、调用计费标准的录入与归档界面，支持合同扫描件与元数据的强绑定。
技术支撑：数据服务协议采用电子合同（e签宝/法大大），具备法律效力。系统底层采用非对称加密技术对商业合同文件资产执行高强度存储加密。

10.3.2 合作协同
1.生态合作意向一键提报（原子子程序）
描述：为了方便尚未深度接入系统的保险公司申请入驻，平台提供一个开放式的商务合作接口，用于合法收集意向机构的企业信用信息、期望承包林区等业务诉求。
功能：接收外部保险机构填写的商务意向表单，核验统一社会信用代码等企业资质材料的格式合法性，将其安全写入平台后台商务待办任务池。

商务意向表单接收
保险公司输入的机构法人全称、企业资质证明材料、拟承保的林区范围描述
前端校验通过的原始意向结构化表单
开放外部未登录入驻通道，提供结构化界面捕获保险机构提报的合作模式、期望对接的林业局名称、业务负责人姓名及手机号。
企业信用代码合规核验
表单中填写的企业统一社会信用代码（18位字符串）
格式校验通过标志位/非法输入驳回提示
调用企业代码校验标准正则表达式，核验其 18 位编码的组织机构代码、类别代码及最后一位校验码的数学逻辑是否合规，杜绝虚假企业填报。
期望承保空间语义解析
拟承保的林区范围描述文本（如“需要承保整个红星林场及周边林区”）
提取出的标准化林业行政区划业务代码清单
调用自然语言分词组件，提取描述文本中的地理实体词，与系统内部标准的林场、区县名称进行匹配，将其翻译为系统可识别的代码。
商务任务待办池注入
校验通过的表单、标准化林业行政区划业务代码清单
平台商务运维后台生成的唯一的待处理合作意向单记录
将通过合规审查的表单数据、资质文件临时存储路径及解析的区划代码强行绑定，生成商务待办单持久化写入运营池，触发专人跟进提醒。
2.商业合作合同数字化建档（原子子程序）
描述：在双方商务洽谈达成一致后，需要将正式签署的商业合同（包括服务费率、结算账期、API 调用调用额度上限）在系统底层进行数字化备案，用于驱动后续系统的流控网关。
功能：提供合同扫描件及元数据字段的强绑定录入界面，将合同中约定的专线带宽与限流参数自动写入 API 网关控制策略库中。

正式合作协议电子化录入
经双方加盖公章的正式纸质合同 PDF 扫描件、合同元数据表单（含到期时间、年费金额）
数据库中初始状态为“待生效”的合同数字档案
商务操作员将线下签署完毕的合同电子版上传至系统，填写合同编号、开始日期、截止日期以及涉及的费用梯度方案，初始化合同记录。
限流控制技术参数提取
合同元数据表单中填写的服务级别参数（如“专线月调用额度上限：10000次；QPS限制：5次/秒”）
结构化的 API 流量控制网关策略字典
提取合同表单中约定的技术调用配额上限与突发每秒请求数（QPS）阈值，将其转换为网关策略组件可识别的结构化频率规则字典。
网关流控策略实时刷新
结构化的 API 流量控制网关策略字典、该保险公司的专属调用凭证密钥（API_Key）
分布式 API 网关内存中的最新限流规则缓存树
将限流规则字典与保险公司的系统专线账户 ID 及网关路由主键进行强绑定，调用 Redis 发布订阅机制，实时将最新配额同步刷新到全局 API 网关的动态限流内存缓存中。
专属服务通道状态激活
网关内存中的最新限流规则缓存树、合同开始时间戳
变更后的合同状态及该保险公司的专属专线网络入口访问权限
检查合同生效时间，一旦到达生效节点，系统自动将该合同状态置为“履约中”，反向开通该保险公司专属 API 账户的访问控制网络白名单，协同通道正式宣告开通。
